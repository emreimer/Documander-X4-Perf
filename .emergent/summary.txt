<analysis>**original_problem_statement:**
The user wants to build a platform called Documander for accountants, intended to be embedded in their Wix website (). The core functionality involves users uploading customer invoices (PDF, JPG, XML, HTML), with an AI extracting the data for categorization into Income and Expense. Users can then download an Excel file of these invoices.

PRODUCT REQUIREMENTS:
1.  **Wix Integration:** The application must be embedded in a Wix website. User identification is managed via the Wix Member ID.
2.  **Subscription System:**
    *   **Paid Plans:** Valid for 12 months with a single, total quota for the entire period. Quotas do not reset monthly.
    *   **Multiple Packages:** Users can purchase new plans at any time. The new quota and validity period are added to their existing ones. The system tracks each package's usage and expiry individually.
    *   **Automatic Sync:** New plan purchases on Wix are automatically added to the user's account in Documander via a webhook.
    *   **Free Trial:** 20 invoices with a 7-day expiry for new users.
3.  **Access Control:** The application must only be accessible when embedded within the authorized Wix domain.
4.  **Taxpayer Sessions:** Users must create a session (taxpayer name, year, month) before they can upload or view invoices.
5.  **AI Data Extraction:** An AI must extract data from uploaded invoices, including handling multiple invoices from a single file and validating dates.
6.  **KDV (VAT) Report:** A new report page that provides a detailed breakdown of VAT (%1, %10, %20) and withholding tax for all invoices in the selected period. It must also include a summary table with totals for each VAT rate.
7.  **Admin Panel:** A secure admin dashboard for the owner to view a list of all users, their contact information (name, email), and a detailed breakdown of all their active/expired packages, including usage and remaining quotas.
8.  **Excel Export:** Provide separate export options for Income, Expense, and All invoices.

**User's preferred language**: Turkish
