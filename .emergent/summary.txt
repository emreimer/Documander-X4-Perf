<analysis>**original_problem_statement:**
The user wants to build a platform for accountants. The core functionality is to allow users to upload customer invoices in various formats (XML, PDF, JPG), and in return, receive an Excel file that serves as an income and expense statement. This statement should contain summary information from the invoices. The user has specified that AI should be used to extract data from the uploaded invoice files.

**PRODUCT REQUIREMENTS:**
1.  User authentication (JWT-based).
2.  Bulk invoice upload supporting PDF, JPG, and XML.
3.  AI-powered data extraction from invoices.
4.  Invoices categorized as Income and Expense, displayed in separate tables.
5.  Each table should display a sub-total of the invoice amounts.
6.  The UI should show specific columns for each category (e.g., 'Customer' for income, 'Issuer' for expense).
7.  A single Download Excel button to export all invoices (both categories) into one file.
8.  The exported Excel file and the UI should sort invoices by date.
9.  The Excel file should use Turkish number formatting (e.g., 1.234,56).
10. A paid subscription system using the PayTR payment gateway.

**User's preferred language**: Turkish

A full-stack application (FastAPI + React) with JWT-based user authentication. The dashboard displays two separate tables for Income and Expense invoices. A single button allows exporting all invoices to an Excel file, which is sorted by date and has Turkish number formatting. The database schema and API endpoints support all required fields, including customer/issuer details, tax information, and an invoice content summary.
